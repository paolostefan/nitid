Nitid syntax is largely borrowed from the C language, with a few notable exceptions:

* no preprocessor directives are allowed;
* functions have an explicit `fn` keyword (see [Functions](#functions));
* packages.

## Types

Base data types follow.

* boolean type: `bool`
* signed integral types: `i8`, `i16`, `i32` (alias `int`), `i64`, `i128`
* unsigned integral types: `u8`, `u16`, `u32` (alias `uint`), `u64`, `u128`
* float types: `f32` (alias `float`), `f64` (alias `double`)
* string types: `string` (UTF-8 string), `string16` (UTF-16 string), `string32` (UTF-32 string).

## Literals

### Numbers

All the following are valid **Nitid** number literals:

```
123
1 000 000 000
-2.34567
-9.876e-10
0x1000
0XFFFFFFFF
0xff ff ff ff
```

## Identifier names

Identifiers (variable names, function names, package names) must respect this regex:  
`[a-zA-Z_][a-zA-Z0-9_]*`

That is: **start** with an ASCII letter or an underscore, optionally followed by ASCII letters, underscores and numbers.

No punctuation marks, $,%,£,§.ç, accented letters or non-ASCII chars are allowed.

Legal variable name samples:

* _
* a
* GustavoZen0n3

## Variables

### Declaration

Variables can be declared by specifying their type before their names, just as in C:

```c
int v;   
i128 largeInt;    
```    

### Assignment

Variables can be assigned a literal or the value of a variable of the same type:

```c
int a;       // Declare a    
a = 123;     // Assign a    
int b = 456; // Declare and assign b    
```    

### Declare and assign at once

If there's no ambiguity, the variable type can be omitted when using `:=` to declare and assign value at once.
Otherwise, the parser default to the best guess depending on the context.

```go
s := "Hello, world!"; // UTF-8 string type    
c := 'A';             // 8-bit char/int type    
i := 12;              // assuming 32-bit int type    
precise_i := i64(12); // explicitly asking for a 64-bit int    
j := precise_i;       // j is also a 64-bit int   
```

## EBNF Grammar

The following EBNF describes the exact syntax accepted by the current parser implementation. Precedence climbs from low
(top) to high (bottom) in the expression hierarchy.

```ebnf  
(* --- Top Level --- *)  
Program     = PackageDecl , { Import } , { ( FnDecl | Stmt ) } .  
PackageDecl = "package" , Ident , ";" .  
Import      = "import" , Ident , [ "as" , Ident ] , ";" .  
  
(* --- Functions --- *)  
FnDecl      = "fn" , Ident , [ ParamList ] , [ ReturnTypes ]  
            , "{" , { Stmt } , "}" .  
ParamList   = "(" , [ Param , { "," , Param } ] , ")" .  
Param       = Type , Ident , { "," , Ident } .  
ReturnTypes = "->" , ( "(" , Type , { "," , Type } , ")" | Type ) .  
  
(* --- Types --- *)  
Type        = "i8" | "i16" | "i32" | "i64" | "i128" | "i256"  
            | "u8" | "u16" | "u32" | "u64" | "u128" | "u256"  
            | "f8" | "f16" | "f32" | "f64"  
            | "int" | "float" | "double"  
            | "string" | "string16" | "string32"  
            | "bool" | "void" .  
  
(* --- Statements --- *)  
Stmt        = ReturnStmt | IfStmt | WhileStmt | Block  
            | VarDecl | DeclAssign | ExprStmt .  
ReturnStmt  = "return" , [ Expr , { "," , Expr } ] , ";" .  
IfStmt      = "if" , Expr , "{" , { Stmt } , "}"  
            , [ "else" , ( IfStmt | "{" , { Stmt } , "}" ) ] .  
WhileStmt   = "while" , Expr , "{" , { Stmt } , "}" .  
Block       = "{" , { Stmt } , "}" .  
VarDecl     = Type , Ident , { "," , Ident } , [ "=" , Expr ] , ";" .  
DeclAssign  = [ Type ] , Ident , { "," , Ident } , ":=" , Expr , ";" .  
ExprStmt    = Expr , ";" .  
  
(* --- Expressions (precedence, low → high) --- *)  
Expr        = Assignment .  
Assignment  = Or , [ "=" , Expr ] .  
Or          = And , { "||" , And } .  
And         = BitOr , { "&&" , BitOr } .  
BitOr       = BitXor , { "|" , BitXor } .  
BitXor      = BitAnd , { "^" , BitAnd } .  
BitAnd      = Equality , { "&" , Equality } .  
Equality    = Comparison , { ( "==" | "!=" ) , Comparison } .  
Comparison  = Shift , { ( "<" | ">" | "<=" | ">=" ) , Shift } .  
Shift       = Term , { ( "<<" | ">>" ) , Term } .  
Term        = Factor , { ( "+" | "-" ) , Factor } .  
Factor      = Unary , { ( "*" | "/" | "%" ) , Unary } .  
Unary       = [ "-" | "!" | "~" ] , Primary .  
Primary     = IntLit | FloatLit | StringLit | CharLit  
            | "true" | "false"  
            | Ident , [ "(" , [ ExprList ] , ")" ]  
            | "(" , Expr , ")" .  
ExprList    = Expr , { "," , Expr } .  

whitespace = " " | "\t" ;

(* --- Lexical Elements --- *)  
Ident       = ( letter | "_" ) , { letter | digit | "_" } .  
IntLit      = decimal | hex .
decimal     = digit , { [ whitespace ] digit } .  
hex         = "0x" , hexdigit , { hexdigit }  
            | "0X" , hexdigit , { hexdigit } .  
FloatLit    = digit , { digit } , "." , { digit }  
            | digit , { digit } , [ "." , { digit } ]  
            , ( "e" | "E" ) , [ "+" | "-" ] , { digit } .  
StringLit   = '"' , { ? any char except '"' or '\' ?  
            | escape_seq } , '"' .  
CharLit     = "'" , ( ? any char except "'" or '\' ?  
            | escape_seq ) , "'" .  
escape_seq  = "\\" , ( "n" | "t" | "r" | "\\" | "\"" | "'" | "0" ) .  
  
(* Character classes *)  
letter      = "A" | "B" | ... | "Z" | "a" | "b" | ... | "z" | "_" .  
digit       = "0" | "1" | ... | "9" .  
hexdigit    = digit | "A" | "B" | ... | "F" | "a" | "b" | ... | "f" .  
```  

**Operator precedence summary** (lowest first):

| Level          | Operators                        | Associativity  |     |
|----------------|----------------------------------|----------------|-----|
| Assignment     | `=`                              | right          |     |
| Logical OR     | &#124;&#124;                     | left           |     |
| Logical AND    | `&&`                             | left           |     |
| Bitwise OR     | &#124;                           | left           |     |
| Bitwise XOR    | `^`                              | left           |     |
| Bitwise AND    | `&`                              | left           |     |
| Equality       | `==` `!=`                        | left           |     |
| Comparison     | `<` `>` `<=` `>=`                | left           |     |
| Shift          | `<<` `>>`                        | left           |     |
| Addition       | `+` `-`                          | left           |     |
| Multiplication | `*` `/` `%`                      | left           |     |
| Unary          | `-` `!` `~`                      | right (prefix) |     |
| Primary        | literals, idents, calls, `(...)` | —              |     |
