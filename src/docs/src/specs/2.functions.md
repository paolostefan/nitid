In Nitid, a function is declared and implemented **in the same place**, as opposed to the C paradigm of declaration in a `.h` file and implementation in the corresponding `.c` file.  
A function definition is introduced by the `fn` keyword.
The function body must be enclosed in curly braces (just like in C, Rust, Go, Java...).

### Parameters

Function parameters must be specified **between parentheses**, as a comma-separated list, right after the function name.

Functions that do not require parameters can **omit argument parentheses**. 

The type of each parameter must be specified **before** its name (i.e. `int param`, just like in _C_).
Multiple, consecutive parameters of the same type can be preceded by their type just once (i.e.
`int param1, param2, param3`, somewhat like _Go_). 

```nitid
// Function without parameters: both syntaxes allowed  
fn paramLessFunction() {  
  // ...  
}  
  
fn anotherParamLessFunction {  
  // ...  
}  
// Function with different type parameters  
fn funcName(i16 Param1, string Param2) {  
  // ...  
}  
  
// Function with parameters of the same type "grouped"  
fn otherFuncName(int Param1, Param2, string StrParam1, StrParam2, StrParam3) {  
  // ...  
}  

```
  
### Return values  
  
Function returning one or more values must have `->` right after their name and (optional) parameter list, 
followed by the **return value types** enclosed in parentheses.

Functions returning just one value may omit parentheses around the return type.  

```nitid
// Function with one return value
fn sumFileSizes(string path1, path2, path3) -> i64 {  
    // ...
}  

// Function without parameters returning one value  
fn calcGlobalTemperature -> float {  
  // ...
}

// Function with 3 return values  
fn getFileSizes(string path1, path2, path3) -> (i64, i64, i64) {  
    // ...  
}  
  
// Function without parameters returning 3 values  
fn getPiggiesName -> (string, string, string) {  
  // ...  
}  
```
  
### Calls
  
Functions must be called by specifying their name **followed by parentheses** enclosing a comma-separated list of 
arguments (if any).   
  
```nitid
// Call a func with no args
paramLessFunction();

// Call a func with args  
funcName(42, "No stairway to heaven");  
```
  
### Special functions
  
The only special function name handled by Nitid is `main`.   
If a package contains a function named  `main`, that package will be built as a CMake executable target and the 
executable entry point will be its `main` function.
